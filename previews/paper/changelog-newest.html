Keyline Icons v1.1.0: React Native support and 114 new drawings

Released · 23 Sept 2026

114 drawings added since 1.0.0, bringing the set to 1114, and 1 redrawn.

React Native

The full set now works in React Native apps, Expo included, as @keyline-icons/react-native. Same names, styles and corners as the React package. Shared code between web and phone only changes the package name. On phone, color comes from a color prop: there's no text color to inherit.
